# PDF Rendering (`to-pdf`)

`to-pdf` replays the line layout stored in the document (the `hp:linesegarray` cache 한컴 writes on save). It does not break lines itself, which is why its output matches what 한컴 showed — and why it needs that cache.

## The command for "한컴에서 본 것과 같게"

```bash
hwpforge to-pdf doc.hwpx -o doc.pdf --discovery platform --json
```

The input format is detected by content, so a `.hwp` (HWP5) goes in directly. Without `-o` the PDF is written next to the input with a `.pdf` extension.

## Fonts

| Option                           | Searches                                                                                                                   | Use when                                                                                                             |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `--discovery explicit` (default) | only `--font-dir` directories                                                                                              | reproducible builds with a pinned font directory — with no `--font-dir` it finds nothing and fails `FONT_UNRESOLVED` |
| `--discovery hancom`             | `--font-dir` + the 한컴오피스 bundle (`/Applications/Hancom Office HWP.app/Contents/Resources/Hnc/Shared/TTF`, macOS only) | macOS with 한컴오피스, and you want only 한컴's own faces                                                            |
| `--discovery platform`           | `--font-dir` + 한컴 bundle + system font dirs (`~/Library/Fonts`, `/Library/Fonts`, `/System/Library/Fonts` on macOS)      | the general default                                                                                                  |
| `--font-dir DIR` (repeatable)    | the given directories                                                                                                      | Linux, CI, air-gapped hosts: point it at a directory holding the document's fonts (함초롬바탕, 함초롬돋움, …)        |

A face is matched by name; there is no silent substitution. `--degraded` renders missing bold/italic faces as regular, missing characters as tofu (□), a character shape whose language axes name different fonts with its 한글-axis font, and skips images it cannot render; **it does not rescue an unresolved body font** (`FONT_UNRESOLVED` still fails) and it changes how the page looks. Do not add it to a request for a faithful PDF; use it only when the user accepts the difference, and tell them about the warnings it produces.

## Which documents render

| Document                                                                                                                                                                                                                                               | Renders?                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.hwpx` saved by 한컴                                                                                                                                                                                                                                  | yes, unless it holds content from the next two rows                                                                                                                                                 |
| a paragraph holding a 누름틀 or other field, memo, footnote, equation, hyperlink, cross-reference, index mark, 글자 겹치기, chart, drawn shape (line, rectangle, ellipse, arc, curve, polygon, connector) or anchored text box, or two anchored images | no — `INVALID_CACHE`, even when 한컴 saved it; re-saving does not help                                                                                                                              |
| a table with a non-default position, or non-text content in a table cell                                                                                                                                                                               | no — `UNSUPPORTED_CONTENT` (`kind` names it); re-saving does not help                                                                                                                               |
| `.hwp` given directly to `to-pdf`                                                                                                                                                                                                                      | yes when it carries a saved layout, converted with the cache internally (5 of the 10 `.hwp` fixtures rendered; the 3 chart samples have none: `NO_RENDERABLE_CACHE`); the same content limits apply |
| `convert-hwp5 --carry-layout-cache` output                                                                                                                                                                                                             | yes — for PDF replay and comparison only; do not hand it to 한컴 to reopen                                                                                                                          |
| `convert` (Markdown) or `from-json` output                                                                                                                                                                                                             | no — `NO_RENDERABLE_CACHE`                                                                                                                                                                          |
| after `patch`                                                                                                                                                                                                                                          | yes, but changed paragraphs keep their old line breaks; text that grew overflows (`LINE_OVERFLOW` warning)                                                                                          |
| after `fill`                                                                                                                                                                                                                                           | the filled paragraphs have no cache: skipped (`PARAGRAPH_SKIPPED`), or `NO_RENDERABLE_CACHE` when a whole section loses it                                                                          |
| after `insert-para` / `delete-para`                                                                                                                                                                                                                    | paragraphs from the edit point on are skipped (`PARAGRAPH_SKIPPED`)                                                                                                                                 |
| any table without its layout cache (a table in a `convert` output, or a table one of whose cell paragraphs has no cache)                                                                                                                               | always fails: `MISSING_LAYOUT_CACHE`, even without `--partial-cache-reject` (the message says "under Reject policy" regardless)                                                                     |

For a PDF of edited content, open the edited `.hwpx` in 한컴, save it, then run `to-pdf`. A re-save restores a missing cache only; for the content in the `INVALID_CACHE` and `UNSUPPORTED_CONTENT` rows above, export the PDF from 한컴 instead. `--partial-cache-reject` turns "skip cacheless plain paragraphs with a warning" into a failure (`MISSING_LAYOUT_CACHE`); tables are never skipped — use it when a silently incomplete PDF would be worse than none.

## Output

Success (`--json`):

```json
{
  "status": "ok",
  "input": "t.hwpx",
  "output": "t.pdf",
  "detected_format": "hwpx",
  "size_bytes": 6050,
  "warnings": [],
  "warning_counts": { "input": 0, "convert": 0, "decode": 0, "render": 0 }
}
```

The CLI object has no page count (Python's report has `pages`). Each warning is `{stage, code, message, location?}` (`location` only when the warning has one) — for example `{"stage":"render","code":"LINE_OVERFLOW","message":"line exceeds its cached box by 225423 HWPUNIT …","location":"s0/p0/l0"}`. Report them to the user.

Failure is `PDF_RENDER_FAILED` (exit 2) with the reason in a nested `cause: {stage, code, kind?, location?}` — for example `{"stage":"render","code":"NO_RENDERABLE_CACHE","location":"s0"}`, or `{"stage":"render","code":"FONT_UNRESOLVED"}` with no location:

The CLI `hint` is the same text for every cause ("cacheless documents need a Hancom re-save …"), so branch on `cause.code`. The 20 codes (`PdfErrorCode` in `hwpforge-smithy-pdf`); "measured" = seen on the 0.16.6 fixtures with `--discovery platform`:

| `cause.code`                                                                                      | Next step                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `FONT_UNRESOLVED`                                                                                 | `--discovery platform`, or `--font-dir` pointing at the named font                                                                                                                                                                                                                                                                                                                                                                                                          |
| `FONT_STYLE_UNAVAILABLE`, `GLYPHS_UNAVAILABLE`                                                    | the font has no bold/italic face (measured), or lacks a character (measured). Point `--font-dir` at a copy of that font that has the face or character; `--degraded` renders regular or tofu (□) with a warning instead (measured) if the user accepts the difference                                                                                                                                                                                                       |
| `FONT_AXIS_MISMATCH`                                                                              | one character shape names different fonts per language axis (한글, Latin, …); the message lists them. No font file is missing, so `--font-dir` does not help. `--degraded` renders every axis with the 한글-axis font and warns (`FONT_AXIS_FALLBACK`); otherwise set one font for all axes in 한컴 and re-save                                                                                                                                                             |
| `FONT_EMBED_RESTRICTED`                                                                           | embedding permission is refused or can't be verified (fail-closed): license `Restricted`, no-subsetting or bitmap-only bit (the PDF embedder always subsets outlines), missing OS/2 table, malformed permission bits, or font data that fails to parse. The message names the reason; report it. `--degraded` fails too. Use another font file                                                                                                                              |
| `FONT_FACE_AMBIGUOUS`                                                                             | HwpForge cannot tell which font face is meant: one font file whose subfamily name contradicts its own bold/italic flags, or two different font files tied for the same name and style (identical copies do not count). `detail` names the contradicting file or lists the tied files: remove that candidate from `--font-dir`, or fix or replace the font whose metadata is wrong                                                                                           |
| `FONT_IO`                                                                                         | a `--font-dir` directory or font file cannot be read, or font data cannot be parsed for text shaping: fix the path or use another copy of the font                                                                                                                                                                                                                                                                                                                          |
| `NO_RENDERABLE_CACHE`                                                                             | the section has no layout cache (measured) — re-save in 한컴 (or, for an HWP5 source, pass the `.hwp` directly)                                                                                                                                                                                                                                                                                                                                                             |
| `MISSING_LAYOUT_CACHE`                                                                            | a table (or the paragraph hosting it) has no cache (measured) — always fatal; or, with `--partial-cache-reject`, any paragraph lacks one. Re-save in 한컴                                                                                                                                                                                                                                                                                                                   |
| `INVALID_CACHE`                                                                                   | message with "non-text run … is not renderable" or "anchored images in one paragraph" (measured): content from the table above, not renderable in 0.16.6; re-saving does not help, export the PDF from 한컴. Message with "saved first-fragment height" (measured on two image fixtures): whether a re-save helps is not measured. Any other message (text positions out of order, an anchored image mixed with inline objects, and more): not measured; report the message |
| `UNSUPPORTED_CONTENT`                                                                             | content outside the renderer's scope, named by `kind`. Measured: `non-default table position`, `non-text content in table cell` — re-saving does not help. Other kinds (for example `malformed table grid`, `table nesting too deep`, `multiple tables in one paragraph`): not measured; report the `kind` and message                                                                                                                                                      |
| `IMAGE_DATA_MISSING`, `UNSUPPORTED_IMAGE_FORMAT`, `IMAGE_DECODE_FAILED`, `INVALID_IMAGE_GEOMETRY` | an image cannot be drawn; `--degraded` skips it with a warning                                                                                                                                                                                                                                                                                                                                                                                                              |
| `IMAGE_ASSET_CONFLICT`                                                                            | two different images under one key; fails even with `--degraded`. Report the message                                                                                                                                                                                                                                                                                                                                                                                        |
| `AMBIGUOUS_HEADER_FOOTER`                                                                         | several header/footer candidates match one page, or odd/even headers span several sections; HwpForge does not pick one. No option fixes it; report the message                                                                                                                                                                                                                                                                                                              |
| `STYLE_UNAVAILABLE`                                                                               | a character shape has no font name or size in the style table; no option fixes it. Report the message                                                                                                                                                                                                                                                                                                                                                                       |
| `INTERNAL_INVARIANT`                                                                              | a HwpForge defect; report the message                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `BACKEND`                                                                                         | the PDF writer failed: an invalid page size in the document, a font file it cannot parse (message "failed to parse font" — try another copy of the font via `--font-dir`), an image size it rejects (message "krilla rejected image size …" — earlier checks should have caught this, so report it as a HwpForge bug), or a writer error. Report the message                                                                                                                |

A file that is neither HWPX nor HWP5 fails `UNRECOGNIZED_FORMAT`.

## Python

```python
from hwpforge import Document
res = Document.open("doc.hwpx").to_pdf(discovery="platform")   # also font_dirs=[...], degraded=, partial_cache_reject=
open("doc.pdf", "wb").write(res.data)
print(res.report)   # {'pages': 1, 'warnings': []}
```

Python's `degraded=True` behaves like the CLI flag: an unresolved body font still raises `PDF_RENDER_FAILED`.
